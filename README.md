# Sound Blaster X7 USB Driver & Control Panel Mod

${\color{red}WARNING! \space Use \space At \space Your \space Own \space Risk!}$

This project provides a modified driver and a modified control panel for Sound Blaster X7 sound cards, which otherwise do not support the 'Dolby Digital Live' and 'DTS Connect' Encoders.

Although the Sound Blaster X7 does not natively support Dolby Digital Live or DTS Connect, these features have been enabled through modifications. You can now use Dolby Digital Live and DTS Connect, along with a newly tuned software DSP designed to deliver sound as close as possible to that of the SB-Axx1.
Because the Dolby Digital Live and DTS Connect encoder is a software encoder, hardware processing of the SB-Axx1 processor cannot be applied. Therefore, I implemented the software effect, which allows the software effect to be applied at the Dolby Digital Live and DTS Connect output.

<br/>

## Installation
Go to the [Releases](https://github.com/kgtmaven/SB1580Mod/releases/tag/SB1580) page and download the zip file. and extract the files, and reboot in 'Disable driver signature enforcement' mode. then run "setup.exe".

<br/>

## Notes
 - When installing the driver, you must boot in 'Disable driver signature enforcement' mode.
